# Lecture Lens MVP

YouTube 또는 Zoom 강의 화면에서 코드 영역을 읽고, 검토한 결과를 Antigravity
작업 폴더에 적용하는 Windows용 멘토 보조 도구입니다.

## 현재 지원 범위

- 별도 Chrome·Zoom 창 선택 및 백그라운드 창 캡처
- 드래그 방식의 코드 영역 지정
- 선택 영역 안에서 줄 번호를 가리는 왼쪽 제외선
- 영문 코드와 한글 주석·문자열을 함께 읽는 로컬 PP-OCRv5
- 줄 번호·공백 표시와 문법 강조를 제공하는 검수 코드 편집기
- OCR 원문을 별도 보관하고 대상 파일과 변경 비교
- 화면에 보이는 일부 코드만 인식해도 기존 파일의 앞뒤와 일치 줄을 보존하는 증분 병합
- 수동 캡처와 화면 안정화 기반 자동 감지
- 흰색·검은색 비정상 프레임 차단
- 확대·축소 및 큰 레이아웃 변화 시 자동 감시 중단
- 신뢰도와 기본 코드 검사를 통과한 변경의 안전 자동 반영
- 마지막 작업 폴더·파일·캡처 영역 설정 기억
- 기존 파일과 줄 단위 diff 검토
- Antigravity 작업 폴더 내부의 코드 파일에 적용
- 외부 파일 변경 충돌 방지
- 덮어쓰기 전 `.lecture-capture/history` 백업

이미지와 인식된 코드는 외부 서버로 전송되지 않습니다. Chrome 로그인 정보에도
접근하지 않습니다.

## 실행

1. Node.js 20 이상이 설치되어 있어야 합니다.
2. 처음 한 번 `npm.cmd install`을 실행합니다.
3. `start-lecture-lens.cmd`를 더블클릭하거나 터미널에서 `npm.cmd start`를 실행합니다.

상위 OCR 실행 환경이 없는 개발 PC에서는 Python 3.12로 다음 명령을 한 번 실행합니다.
환경이 없거나 엔진 구동에 실패하면 앱은 기존 Tesseract OCR로 자동 전환됩니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-ocr.txt
```

## 사용 순서

1. YouTube 라이브를 별도 Chrome 창에서 열거나 Zoom 화면 공유에 입장합니다.
2. 강의 창을 최소화하지 않고 다른 작업 창 뒤에 둡니다.
3. Lecture Lens에서 `창 선택`을 누르고 해당 Chrome 또는 Zoom 창을 선택합니다.
4. 미리보기에서 편집기의 코드 부분만 드래그합니다.
5. 청록색 `줄 번호 제외` 선을 드래그해 줄 번호 바로 오른쪽에 둡니다.
6. Antigravity가 연 작업 폴더와 대상 파일을 선택합니다.
7. `지금 코드 읽기`로 검수 코드를 확인합니다.
8. `OCR 원문`과 `변경 비교` 탭을 확인하고 필요하면 코드를 직접 수정합니다.
9. `Antigravity에 적용`을 누릅니다.

`자동 감지`는 화면 변화가 두 번의 캡처에서 안정적으로 유지된 경우에만 OCR을
실행합니다. 강사가 입력 중인 중간 상태를 줄이기 위한 안전장치입니다.

`안전 자동 반영`은 선택 기능이며 기본 동작은 검토 후 수동 적용입니다. 활성화하면
설정한 OCR 신뢰도, 비정상 문자, 줄 번호 혼입, 괄호·따옴표 짝과 기본 Python 블록
형식을 검사한 뒤 조건을 모두 통과한 코드만 파일에 저장합니다. 흰 화면이 연속 두 번
감지되거나 화면 배치가 크게 바뀌면 자동 감시가 중단됩니다.

마지막 작업 폴더, 대상 파일, 캡처 영역과 자동 반영 설정은 앱에 저장됩니다. Chrome
창 식별자는 실행마다 달라질 수 있으므로 앱을 다시 시작한 뒤에는 `창 선택`만 다시
해야 합니다. 같은 제목의 창을 선택하면 저장된 영역이 복원됩니다. `Alt+R`을 누르면
영역을 빠르게 초기화할 수 있습니다.

## 운영상 제한

- Chrome 창을 최소화하면 빈 화면이 반환될 수 있습니다.
- Zoom의 화면 공유 배치나 참가자·채팅 패널이 바뀌면 영역을 다시 지정해야 할 수 있습니다.
- 첫 PP-OCRv5 실행은 모델 초기화로 수 초가 더 걸릴 수 있습니다.
- 작은 Zoom 글씨나 한글과 영문이 한 줄에 섞인 경우 일부 문자가 틀릴 수 있으므로
  자동 반영 전 결과를 확인하는 것이 안전합니다.
- 자동 파일명/탭 추적과 스크롤 병합은 아직 지원하지 않습니다.
- Antigravity에서 같은 파일에 미저장 변경이 있으면 충돌할 수 있으므로 적용 전
  저장하는 것이 안전합니다.
